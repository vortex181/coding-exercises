# تمرین ۱: اولین صفحه‌ی وب

**مفاهیم:** ساختار سند HTML، تگ‌های متنی، لیست، لینک، تصویر، جدول

## هدف
یک صفحه‌ی معرفی شخصی بساز.

## الزامات
- [ ] یک `h1` با نام تو و یک `h2` برای هر بخش
- [ ] یک پاراگراف درباره‌ی خودت
- [ ] لیست نامرتب (`ul`) از علاقه‌مندی‌ها و لیست مرتب (`ol`) از اهداف یادگیری
- [ ] یک تصویر با `alt` مناسب
- [ ] یک لینک به سایت دلخواه که در تب جدید باز شود
- [ ] یک جدول برنامه‌ی هفتگی با `thead` و `tbody`

## چالش اضافه
از تگ‌های معنایی `header`، `main`، `section` و `footer` استفاده کن.
