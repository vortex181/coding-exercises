# تمرین ۳: اولین جاوااسکریپت

**مفاهیم:** متغیر، تابع، رویداد، `querySelector`، `textContent`

## هدف
صفحه‌ای بساز که به کلیک و ورودی کاربر واکنش نشان بدهد.

## الزامات
- [ ] دکمه‌ی شمارنده: هر کلیک یکی اضافه کند
- [ ] دکمه‌ی ریست که شمارنده را صفر کند
- [ ] با نوشتن نام در input و زدن دکمه، پیام «سلام، <نام>!» نمایش داده شود
- [ ] اگر input خالی بود، پیام خطا نشان بده

## چالش اضافه
شمارنده نباید از ۰ کمتر شود. یک دکمه‌ی «کم کردن» هم اضافه کن.
