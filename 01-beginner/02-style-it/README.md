# تمرین ۲: استایل‌دهی با CSS

**مفاهیم:** سلکتورها، رنگ و فونت، box model، pseudo-class

## هدف
صفحه‌ی بدون استایل را با `style.css` زیبا کن.

## الزامات
- [ ] فونت و رنگ پس‌زمینه‌ی کل صفحه
- [ ] عنوان‌ها وسط‌چین و با رنگ متفاوت
- [ ] کارت اطلاعات با `padding`، `border-radius` و `box-shadow`
- [ ] دکمه‌ای که با `:hover` تغییر رنگ بدهد
- [ ] حداقل یک سلکتور کلاس، یک سلکتور id و یک سلکتور فرزند (`>`)

## چالش اضافه
با `max-width` و `margin: 0 auto` محتوا را در مرکز صفحه نگه دار.
