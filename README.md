# تمرین‌های HTML، CSS و JavaScript

مسیر یادگیری از مبتدی تا حرفه‌ای، با ۱۲ تمرین عملی.

| سطح | تمرین‌ها | تمرکز |
|---|---|---|
| `01-beginner` | صفحه‌ی اول، استایل‌دهی، اولین جاوااسکریپت | تگ‌ها، سلکتورها، متغیر و رویداد |
| `02-intermediate` | کارت‌های ریسپانسیو، لیست کارها، اعتبارسنجی فرم | Flexbox/Grid، DOM، فرم‌ها |
| `03-advanced` | Fetch API، انیمیشن CSS، اپ کوئیز | async، متغیرهای CSS، مدیریت state |
| `04-pro` | مودال دسترس‌پذیر، روتر SPA، بورد کانبان | a11y، معماری، تست، ماژول‌ها |

## روش کار
1. هر پوشه یک `README.md` دارد: ابتدا آن را بخوان.
2. فایل‌های شروع (`index.html`، `style.css`، `script.js`) را باز کن و جاهای `TODO` را کامل کن.
3. `index.html` را در مرورگر باز کن (یا با افزونه‌ی Live Server در VS Code).
4. برای تمرین‌های `04-pro` که تست دارند: `npm test` (نیاز به Node.js 18 یا بالاتر).
5. بعد از حل هر تمرین، چالش اضافه‌ی آن را امتحان کن.

> نکته: گیر کردی؟ ۱۵ دقیقه تلاش کن، بعد جستجو کن.
