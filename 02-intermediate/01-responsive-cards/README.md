# تمرین ۴: کارت‌های ریسپانسیو

**مفاهیم:** Flexbox، CSS Grid، media query، واحدهای نسبی

## هدف
یک گالری کارت بساز که روی موبایل، تبلت و دسکتاپ درست نمایش داده شود.

## الزامات
- [ ] ۶ کارت با عنوان، توضیح کوتاه و دکمه
- [ ] موبایل: ۱ ستون، تبلت: ۲ ستون، دسکتاپ: ۳ ستون (با Grid)
- [ ] فاصله‌ی یکسان بین کارت‌ها با `gap`
- [ ] هدر ثابت بالای صفحه با Flexbox (لوگو راست، منو چپ)
- [ ] از `rem` و `%` به‌جای `px` استفاده کن

## چالش اضافه
بدون media query و فقط با `repeat(auto-fit, minmax(...))` همین نتیجه را بگیر.
