# تمرین ۶: اعتبارسنجی فرم

**مفاهیم:** رویداد `submit`، `preventDefault`، Regex، پیام خطا، UX فرم

## هدف
فرم ثبت‌نام با اعتبارسنجی سمت کلاینت بساز.

## الزامات
- [ ] فیلدها: نام، ایمیل، رمز عبور، تکرار رمز
- [ ] نام حداقل ۳ حرف، ایمیل معتبر، رمز حداقل ۸ کاراکتر شامل عدد
- [ ] تکرار رمز باید برابر باشد
- [ ] پیام خطا زیر هر فیلد نمایش داده شود
- [ ] در صورت موفقیت پیام تأیید نشان بده، بدون ارسال واقعی

## چالش اضافه
نمایشگر قدرت رمز عبور (ضعیف / متوسط / قوی) به‌صورت زنده.
