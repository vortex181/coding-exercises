# تمرین ۵: لیست کارها

**مفاهیم:** ساخت عنصر با DOM، delegation رویداد، آرایه و `filter`

## هدف
یک اپ لیست کارها بساز.

## الزامات
- [ ] افزودن کار با دکمه و کلید Enter
- [ ] تیک زدن کار (خط‌خورده شود)
- [ ] حذف کار
- [ ] نمایش تعداد کارهای باقی‌مانده
- [ ] از ثبت کار خالی جلوگیری کن
- [ ] از **event delegation** استفاده کن (یک listener روی `ul`)

## چالش اضافه
فیلتر «همه / فعال / انجام‌شده» اضافه کن.
